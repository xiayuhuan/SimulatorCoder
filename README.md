# SimulatorGen
SimulatorGen is built on top of the [SCALE Sim](https://github.com/ARM-software/SCALE-Sim) simulator.
# Installation
SimulatorGen interacts with [python3](https://www.python.org/downloads/).
Please install [SCALE Sim](https://github.com/ARM-software/SCALE-Sim) before running SimulatorGen.
# Quick Start
```
python Agent.py
```
You need to modify the path and api_key in Agent.py.

Architecture.txt-Introducing the simulator's architecture.

The folder prompt template contains four prompt word templates.

The folder out records contains the simulation output records.

The folder run results contains the simulation run results.
